# `inputs/` —— 长文种子的题目放这儿

`corpus.json` 里**只写路径**，正文放这个目录：

```jsonc
{ "id": "seed-09", "goal": "inputs/long-form.txt", ... }
```

⚑ 为什么不把 800 / 3000 字塞进 JSON：**没法读也没法写** ——
JSON 是给机器读的格式，一大段中文正文塞进去之后，`corpus.json`
就不再是"一张能一眼扫完的断言表"了，而会变成一份散文。

## ⚠️ 文件不在会怎样

`runner.py` 的 `resolve_goal()` 会**直接报错退出**，不会把路径当目标发出去 ✗。

⚑ 这一条是**特意**的：在补 `resolve_goal()` 之前，README 说支持文件路径、
而 runner 里**没有那段代码** —— 于是 `"inputs/xxx.txt"` 会被原样当成目标
发给模型（"帮我规划一下 inputs/xxx.txt"），拆出来的图看着挺正常，
**报告里一切绿灯** ✗。那正是 #13：错的东西看起来是对的。

（同一个毛病 `distribution` 也犯过一次：数据里写着、runner 不读它。
所以这一类要当成通例防 —— **文档承诺了的东西，代码里得真有**。）
